Bulk Google Forms import

Export your Google Form responses as CSV or XLSX. The first row must contain headers. All supplied columns are preserved as user fields, and the standard IARCO fields are added when missing.

Select a CSV or XLSX file to preview it here.
CSV and XLSX input are supported. Each valid email gets a unique random password. The credential downloads contain CSV and modern Excel .xlsx files. Category is read from the uploaded CSV/XLSX Category column (Junior/Senior). Languages are comma-separated and stored as a JSON array. Participant IDs are generated as YEAR-J/S-01, YEAR-J/S-001, etc.; numbering width is based on total participant count with a minimum of 2 digits.
